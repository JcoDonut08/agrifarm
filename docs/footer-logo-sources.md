# Storefront footer logos

The shared storefront footer displays these original assets beneath the AgriFarm description:

- `public/images/pasig-cenro-seal.jpg`: the seal used by Pasig CENRO's public profile, retrieved from [the profile image endpoint](https://graph.facebook.com/102758618764439/picture?type=large) on October 14, 2026. The user selected this seal to represent CENRO.
- `public/images/pasig-city-wordmark.svg`: Pasig City's wordmark, downloaded unchanged from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Pasig_Wordmark.svg) on October 14, 2026. The file attributes the artwork to the Pasig city government and identifies the official city website as its source.

Both assets are served locally. Their colors and aspect ratios are preserved; the wordmark has a white background in the footer so its dark blue lettering remains readable in both themes.
